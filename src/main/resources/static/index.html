How it works

AST-aware indexEach Java file is parsed with JavaParser into a class outline plus one chunk per method, with exact line ranges.
Hybrid retrievalpgvector similarity and Postgres full-text search on split identifiers, merged with reciprocal rank fusion.
Grounded answersThe model sees numbered sources and must cite them; citations link to the exact lines on GitHub.
Built to run cheaplyTwo-tier answer cache, per-client rate limits and token budgets, and Claude-to-Ollama failover behind circuit breakers.

Also available to AI agents as an MCP server at /mcp. Measured on a labelled 40-question eval: hybrid search finds the right code in the top 5 for 90% of questions.
